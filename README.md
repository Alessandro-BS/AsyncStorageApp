# AsyncStorageApp

Dos ejercicios de almacenamiento local en Android:

| Carpeta | Tecnología | Almacenamiento |
|---|---|---|
| [`Kotlin/`](Kotlin) | Android nativo con Kotlin | SharedPreferences |
| [`ReactNative/`](ReactNative) | React Native (TypeScript) | AsyncStorage |

Cada carpeta tiene su propio README con los pasos para ejecutarla.

- **Kotlin**: abre la carpeta `Kotlin` en Android Studio y pulsa **Run (▶)**.
- **React Native**: entra a `ReactNative`, ejecuta `npm install` y sigue los pasos de su README.
